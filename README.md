# Employee Management System (Laravel CRUD)

A clean and practical Employee Management System built with Laravel.

This project demonstrates core Laravel features such as CRUD operations, AJAX, Bulk Delete, Factory & Seeder, and PDF export.

---

## 📌 Project Overview
This system allows managing employees through a complete CRUD workflow:
- Add new employees
- Update employee information
- View employee records
- Search employees dynamically using AJAX
- Delete multiple employees at once (Bulk Delete)
- Export employee data to PDF

Dummy data is generated using Laravel Factory and Seeder.

---

## ✨ Features
- Create, Read, Update, Delete (CRUD) employees
- AJAX-based search (no page reload)
- Bulk delete employees using checkboxes (AJAX)
- Export employee data to PDF
- Factory & Seeder for test data
- Clean and user-friendly interface
